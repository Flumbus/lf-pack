# lf-pack

Репозиторий сборки для `LittleFlame Launcher`.

Здесь хранится не код лаунчера, а данные самой игровой сборки:

- какая версия Minecraft нужна;
- какой модлоадер нужен;
- какие моды обязательные;
- какие моды опциональные и как их показать в меню лаунчера.

## Структура

```text
launch/
  distribution.json
  mods-manifest.json
mods/
  main/
    mods/
  optionals/
    xaeros/
      mods/
      info.json
    journeymap/
      mods/
      info.json
scripts/
  build-manifest.js
```

## Что для чего

### `launch/distribution.json`

Главная точка входа для лаунчера.

В этом файле фиксируется:

- версия Minecraft;
- версия модлоадера;
- требуемая Java;
- адрес сервера;
- ссылка на технический индекс модов.

Сейчас в шаблоне уже зафиксирована база под:

- `Minecraft 1.21.1`
- `NeoForge 21.1.216`
- `Java 21`

### `launch/mods-manifest.json`

Технический индекс модов для лаунчера.

Он нужен для того, чтобы лаунчер понимал:

- какие файлы скачивать;
- к какому паку они относятся;
- какие паки обязательные;
- какие паки опциональные;
- какие заголовки и описания показывать в меню дополнительных модов.

Важно: руками его лучше не править. Источник правды тут не он, а папки `mods/...`.

### `mods/main/mods/`

Сюда кладутся обязательные `.jar`-моды.

Всё, что лежит здесь, считается основной сборкой и должно ставиться всем игрокам.

### `mods/optionals/<packId>/mods/`

Сюда кладутся `.jar`-моды для конкретного дополнительного пака.

Например:

- `mods/optionals/xaeros/mods/` для Xaero's Minimap
- `mods/optionals/journeymap/mods/` для JourneyMap

### `mods/optionals/<packId>/info.json`

Описание optional-пака для лаунчера.

В этом файле хранится:

- `id` пакета;
- `title` заголовок в UI;
- `description` короткое описание;
- `category` категория;
- `default` включён ли пак по умолчанию;
- `logo` путь к картинке, если она будет использоваться в UI.

### `scripts/build-manifest.js`

Вспомогательный скрипт.

Он проходит по папкам `mods/main` и `mods/optionals`, считает хэши файлов и собирает новый `launch/mods-manifest.json`.

То есть рабочий цикл такой:

1. Кладёшь моды в папки.
2. Обновляешь `info.json`, если это optional-пак.
3. Запускаешь `node scripts/build-manifest.js`.
4. Коммитишь изменения в репозиторий.

## Как добавить обязательный мод

1. Положить `.jar` в `mods/main/mods/`
2. Запустить `node scripts/build-manifest.js`
3. Закоммитить и запушить изменения

## Как добавить optional-мод

1. Создать папку `mods/optionals/<id>/`
2. Положить `.jar` в `mods/optionals/<id>/mods/`
3. Заполнить `mods/optionals/<id>/info.json`
4. При желании добавить `logo.png` или `logo.jpg`
5. Запустить `node scripts/build-manifest.js`

## Важное замечание

Скрипт генерации сейчас собирает ссылки в формате GitHub Raw и ожидает, что репозиторий будет публичным и работать с веткой `main`.

Если позже поменяется:

- владелец репозитория;
- имя репозитория;
- основная ветка;

нужно будет поправить константы в `scripts/build-manifest.js`.
